# What this repo is

Just-for-me plain-text configs. Symlinked into `~/.config` by
home-manager from [nixos](https://github.com/yujiqo/nixos) repo.

Same convention as [yurice](https://github.com/yujiqo/yurice): `config/` mirrors `~/.config`.

- `config/git/config`        - git identity
- `config/opencode`          - opencode
